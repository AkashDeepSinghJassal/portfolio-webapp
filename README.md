# Portfolio

Personal portfolio for Akashdeep Singh Jassal — distributed software engineer.
Built with Next.js (App Router, SSR) as a single-page site. Content lives in `config/`.

## Stack

- Next.js 14
- React 18
- TypeScript

## Setup

```bash
yarn
yarn dev
```

## Production

```bash
yarn build
yarn start
```

Deploy on Vercel for automated builds on push.
